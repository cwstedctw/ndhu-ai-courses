Kaggle 是什麼？這個比賽又在做什麼？

Kaggle 是全世界最大的資料科學競賽平台。主辦方（公司、研究機構）丟出一份資料和一個問題，全球的人寫程式來解，誰的答案最準誰就贏。你不用裝任何軟體——所有程式都在 Kaggle 的雲端 Notebook 裡跑，還免費附 GPU。

本場賽

Biohub — Cell Tracking During Development

CZ Biohub 主辦 · 研究級 Code 競賽 · 獎金 US$60,000

科學家想研究胚胎發育時細胞怎麼移動、分裂，但要在 3D 顯微影片裡用人工一顆一顆追蹤上千顆細胞，曠日廢時。這個比賽就是要大家寫演算法自動做這件事：

🔬

偵測

在每個時間點找出每顆細胞的位置

🔗

連線

把同一顆細胞在前後時間點接起來

🌱

分裂

偵測一顆細胞分裂成兩顆的時刻

🧬

譜系

重建出整棵細胞家族樹

為什麼拿這題當教材？因為它看得到、有畫面、有意義（追蹤活細胞），又是真實在進行的世界級比賽。流程學起來，之後換成任何題目都一樣套。
STEP1

註冊一個 Kaggle 帳號

用 Google 帳號一鍵登入最快
換你動手
  • 打開 kaggle.com，右上角按 Register。
  • 選「Register with Google」，用你的 Google 帳號登入，最省事。
  • 第一次登入要做一次手機簡訊驗證（Phone Verification）——跑 Notebook 和提交都需要驗證過，現在先做好。
眉角：沒做手機驗證的話，之後 Notebook 的 GPU 開不了、也不能提交。第一次就先驗證起來，免得待會卡住。
STEP2

進到比賽頁，按「Join Competition」接受規則

沒加入＝看不到資料、不能交
換你動手
  • 進入比賽頁：kaggle.com/competitions/biohub-cell-tracking-during-development
  • 右上角按 Join Competition → 跳出規則，讀過後按 I Understand and Accept。
  • 接受後，原本鎖住的 Data 分頁就解鎖了，也才能用這個比賽的 Notebook 提交。
比賽頁的 7 個分頁怎麼看： Overview（在幹嘛、怎麼評分）、Data（資料）、Code（別人公開的 Notebook）、Discussion（討論區）、Leaderboard（排行榜）、Rules（規則）。新手最該先看的是 Overview 和 Code。
重要時程（本場）：報名與組隊截止 9/22、最終提交 9/29。要拿名次得在截止前接受規則。純練習、過了截止也還能交著玩，只是不列入排名。
STEP3

動手前，先讀懂三件事：資料、評分、繳交格式

這三件決定你的程式要長什麼樣
看我示範

① 資料長怎樣（Data 分頁）

  • 每筆樣本是一段 3D+時間的螢光顯微影片，存成 .zarr 資料夾，形狀約 (T,Z,Y,X)=(100,64,256,256)。
  • 訓練集還附 .geff 標準答案；測試集只有影像。整包約 87 GB，但不用下載——在 Kaggle Notebook 裡直接掛上來讀就好。

② 怎麼評分（Evaluation 分頁）

# 分數 = 連線正確度 + 0.1 × 細胞分裂偵測
score = adjusted_edge_jaccard + 0.1 * division_jaccard

白話：主要看你「把細胞前後連對」的比例，再加一點「有沒有抓到細胞分裂」。分數可能超過 1.0（指標設計使然）。

③ 繳交格式（submission.csv）——你的程式最後要吐出這個檔：

id,dataset,row_type,node_id,t,z,y,x,source_id,target_id
0,44b6,node,1,0,32,128,128,-1,-1   # 一顆細胞
1,44b6,node,2,1,33,130,125,-1,-1
2,44b6,edge,-1,-1,-1,-1,-1,1,2      # 把 1 號連到 2 號
  • node 列＝一顆細胞偵測，填 node_id, t, z, y, x。
  • edge 列＝一條連線，填 source_id, target_id（指向 node_id）。
  • dataset 要對上測試資料夾名稱；每個測試樣本都要出現。
STEP4

開一個 Notebook，掛上資料，貼進起手式程式

不用裝 Python、不用下載 87GB
看我示範

最快的兩種起手方式，挑一個：

  • A. 直接複製官方範例：到 Code 分頁打開釘選的「Cell Tracking Getting Started w/ Nearest Neighbor」，右上角按 Copy & Edit，它會把程式和資料都幫你掛好，按 Run 就能跑。
  • B. 用我們課堂版 Notebook：本資料夾的 demo_cell_tracking_baseline.ipynb（繁中逐步註解版）。在 Kaggle 按 New Notebook → File → Import 上傳它，再到右側 Add Input 把本比賽資料掛上。
Add Input 是什麼？就是「把這個比賽的資料掛進我的 Notebook」。掛好後，資料會出現在 /kaggle/input/... 路徑下，程式才讀得到。
Code 競賽的硬規定：提交用的 Notebook 必須關閉網路（Internet off）、執行 ≤ 12 小時、輸出檔名一定是 submission.csv。右側 Settings 把 Internet 關掉、要用 GPU 就把 Accelerator 開成 GPU。
STEP5

Run All：讓程式跑出 submission.csv

課堂版約 50 秒跑完，會拿到 ~0.14 分
看我示範

我們的課堂版 baseline 用最樸素的「最近鄰連線法」，一條龍做四步：

📥

① 讀影像

解壓 .zarr，一個時間點一個時間點讀進來

🔬

② 偵測

平滑→取最亮 10%→連通元件→質心當細胞

🔗

③ 連線

相鄰時間點用匈牙利演算法配最近的細胞

💾

④ 輸出

所有 node＋edge 寫成 submission.csv

核心程式其實很短，看得懂的程度：

# ② 偵測：把一個 3D 體積變成一串細胞質心
smoothed = uniform_filter(vol, size=3)          # 平滑去雜訊
binary   = smoothed > np.percentile(smoothed, 90)  # 取最亮的前 10%
labeled, n = label(binary)                       # 連通元件分群

# ③ 連線：相鄰時間點找總距離最小的一對一配對
dist = distance_matrix(prev, curr)               # 兩邊細胞兩兩距離(µm)
rows, cols = linear_sum_assignment(dist)         # 匈牙利演算法
edges = [(p,c) for p,c in zip(rows,cols) if dist[p,c] <= 15]

按 Save Version → Save & Run All (Commit)，讓它從頭乾淨跑一遍。跑完，submission.csv 就會出現在 Notebook 的 Output。

STEP6

提交，到排行榜看自己的分數

🎉 到這裡，你就正式參賽了
換你動手
  • Notebook 跑完（Commit 成功）後，打開它的 Output 分頁，按 Submit。
  • 等系統評分，跳到比賽的 Leaderboard，就看得到你的分數和排名。
  • 同一份 Notebook 可以一直改、一直交——這就是 Kaggle 的玩法：交一次、看分數、再改進。
第一次的分數高低完全不重要。重點是你已經把「註冊→加入→讀規則→寫程式→提交→看分數」整條路走完一遍了。剩下的就是慢慢把分數往上推。
交完第一份之後

然後呢？怎麼把分數往上推

同一個比賽，公開的 Notebook 分數從 0.14 一路到 0.69。差別在哪？看看別人怎麼做，挑一個方向改進自己的。

0.64

改進方向現在的弱點可以試什麼
偵測固定亮度門檻太粗，貼太近的細胞算成一顆peak_local_max、分水嶺、深度學習分割（Cellpose / StarDist）
連線只看「最近」，細胞動快就接錯加運動預測（卡爾曼濾波）、斷掉再接回（gap closing）
細胞分裂完全沒處理，那 0.1× 的分數全丟了偵測「一顆變兩顆」的 division 事件
學習路徑建議：先把課堂版跑通、交一次 → 再開官方範例對照看 → 然後挑「偵測」或「連線」其中一個小改一版、再交一次。每次只動一個地方，才看得出哪招有效。
