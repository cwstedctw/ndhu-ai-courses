我們怎麼教電腦
把每一顆細胞追到底

一個真實的科學難題，我們用一整隊 AI 一步步解開。點點看——分數會從 0.04 一路爬到 0.90，下面那張圖，也會從「亂連一通」變成「幾乎全連對」。

🎬 這到底在解什麼問題？

先用生活想 想像你在看一段從天上拍演唱會的影片。你要一路盯著每一個人：他走到哪、什麼時候有人離場、什麼時候又多了一個人進來。 現在把「人」換成顯微鏡下的細胞，把「演唱會」換成正在長大的胚胎——而且是立體的、上千顆、還會一顆分裂成兩顆。這樣用手一顆一顆追，會追到天亮。

所以科學家想教電腦自己追。追得好不好，有一個分數：從 0 到 1，像考試分數，越高越好。電腦把細胞「前後接對」的比例越高，分數就越高。我們要做的，就是想辦法把這個分數愈拉愈高。

🕹️ 點點看：四個版本，一版比一版聰明

下面有四顆按鈕，各代表一個版本。先看懂這張圖怎麼看，你就會親眼看到「為什麼愈來愈好」。

👆 你點哪個版本，下面這張「追蹤圖」就跟著變——紅線變少、綠線變多，就是變好了：
● ＝ 一顆細胞（某個時間點）
綠線 ＝ 接對了（同一顆細胞，前後接對）
紅線 ＝ 接錯了（接到別顆去了）
↳ ＝ 抓到分裂（一顆變兩顆）
0.04
官方分數
0（亂猜）1（完美）
（自動從起步版一路點到合成版，看圖從紅變綠）

怎麼看這張圖：由左到右是時間（第 1 刻 → 第 4 刻）。每一直行，是同一個時刻裡的所有細胞。那些線，是電腦的猜測：「這顆細胞，下一刻跑到了這裡」。綠線（接對）越多、紅線（接錯）越少，分數就越高。

💡 我們自己想出來的兩招（白話）

最強的「合成版」不是抄來的。「怎麼找到細胞」我們借了網路上厲害的公開做法；但「怎麼把細胞前後接對、怎麼認出分裂」這兩招，是我們自己想的：

🤝

兩邊都點頭才連

連細胞時，不只「從前往後」找最近的一顆，也「從後往前」再確認一次——兩邊都指到對方，才把它們連起來。像兩個人互相點頭「我們同一隊」，比單方面猜準很多。細胞一密集，這招特別有用（紅線會大幅變少）。

⚖️

用物理常識認分裂

一顆細胞分裂成兩顆時，兩顆會往相反方向彈開（像捏著一團東西往兩邊一掰）。我們用這個常識判斷：如果兩顆不是往相反方向，那就不是分裂，只是剛好擦身而過——這樣才不會把「路過」看成「分裂」。

加上這兩招，分數從 0.57 跳到 0.90。我們還特地做了對照實驗證明：多出來的進步，主要是這兩招的功勞，不是抄來的。

🖥️ CPU 還是 GPU？為什麼「便宜的」反而贏

有老師問了一個很好的問題：上面的版本裡，用 GPU 深度學習那版只有 0.57，我們純 CPU 的合成版卻有 0.90——GPU 不是比較高級嗎，怎麼反而輸？這其實是這堂課最值得停下來想的一題。先把兩種晶片想成兩種「個性」：

🧠

CPU ＝ 幾個很會「想」的腦袋

核心不多，但每個都很會一步一步推理、做判斷。適合需要動腦的事——像我們那兩招「兩邊點頭」「用物理認分裂」，骨子裡都是在想清楚，CPU 就很拿手，又快又省電。

👀

GPU ＝ 一大群人同時做同一件小事

幾千個小核心同時開工。適合「把幾百萬個像素一次看完」這種大量又重複的粗活——深度學習認圖就靠這個，所以 GPU 版「找細胞」幾乎一顆不漏。

關鍵在於：這題的分數，不只看「細胞找得準不準」，更看「前後有沒有接對」。 GPU 版很會看（找細胞），但它沒有我們那兩招聰明的追蹤腦袋；我們的合成版是「夠好的找細胞 ＋ 很聰明的接線」，把整件事做完整，所以反而拿到高分。看得清楚是一半，想得清楚是另一半——這一題，想得清楚更值錢。

所以答案不是「CPU 比 GPU 好」，而是看任務挑工具：動腦的邏輯交給 CPU、大量重複的辨識交給 GPU。最理想的，是把 GPU「超會找細胞」和我們「超會接線」兩個長處接在一起——這正是我們接下來在試的下一步。

帶得走的一句話：最新、最貴的工具，不一定最適合你手上的問題。看懂問題、選對方法，便宜的也能贏過昂貴的。這個道理，學生在選工具、選做法的時候都用得上。

🚀 我們真的拿去比賽了

這不是紙上談兵。我們把最強的版本真的送上 Kaggle（全世界的資料科學競賽平台），讓它在我們從沒看過的資料上跑，拿真正的成績。

比賽Biohub 細胞追蹤賽（CZ Biohub 出題）
我們的做法合成版：兩邊點頭連線 ＋ 物理認分裂
排行榜真分數🏆 0.738（贏過所有公開範例，最高才 0.687）
還在做的繼續往上衝，挑戰更高分

註：用練習資料在自己電腦上測，會測到 0.90，但那一定比真排行榜樂觀（沒看過的資料一定更難）。排行榜分數，才是「到底有沒有真的進步」的最終答案。

🎒 這堂課，每個人都帶得走的

  1. 會問問題，比會寫程式更重要——先把「現在怎樣、想要怎樣、卡在哪」講清楚，答案就出來一半了。
  2. 不要只問一個 AI——多問幾個，看是不是都指向同一招。很多人都說好的，通常錯不了。
  3. 判斷和決定，留給人——AI 給你選項，你來挑哪個先試。
  4. 一定要驗證——「看起來會」不等於「真的會」，要用對的尺量過才算數。
  5. 一次只改一個地方——這樣才看得出到底哪一招有效。
  6. 站在巨人肩上——先讀懂別人更厲害的做法，再加上自己的新東西。
